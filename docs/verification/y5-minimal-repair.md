# Y5 minimal repair slice

This slice repairs the bounded presentation/report seams only:

- `ml_plotly_contract.py` and `sandbox-analysis-mcp/ml_plotly_contract.py` accept the bounded Plotly typed-array encoding emitted by the installed Plotly GO/Express bar and scatter producers. Decoding is limited to numeric dtypes, validates base64 and byte alignment, checks the item budget before allocation, and preserves values and order. Integer values outside the downstream-safe `-(2**53 - 1)` through `2**53 - 1` range are rejected rather than rounded. Only the exact installed Plotly default template fingerprint and safe Express defaults (`hovertemplate` generated for x/y, empty `legendgroup`, `textposition=auto`, marker `symbol=circle`, empty marker pattern, and `legend.tracegroupgap=0`) are normalized; a mutated or unknown template is rejected, never stripped. Arbitrary templates, URLs/scripts, unknown fields, malformed arrays, non-finite values, empty arrays, and oversized payloads remain rejected.
- A successful Sandbox execution whose report manifest is rejected retains immutable `sandbox-execution` and host provenance with explicit computation/report statuses. Trusted `execute_ml_contract` and `profile_dataset` outputs may use the existing report-only re-export path without executor calls only when complete provenance is explicitly succeeded/compatible and authenticated code, frame, and plan artifacts recompute the retained digests and bind the question/analysis contract. Re-export records carry paired source execution/provenance refs and a bounded single-hop output/source digest; chains, cycles, altered parent refs, changed retained outputs, missing-error executions, and incompatible statuses fail closed. Generic Python remains blocked from trusted re-export; missing, foreign, mismatched, unreadable, or indeterminate evidence is not synthesized or backfilled.
- Report coverage carries a host-retained question independently of `analysis_contract`, marking it `host_retained_plan` only after lineage verification and `retained_question_unverified` otherwise. The compositor receives that value rather than replacing it with a generic manifest purpose. `not_assessed` and `partial` dashboards show host-generated status/gap notices; these notices do not establish scientific, chat, runtime, deployment, or browser completion.
